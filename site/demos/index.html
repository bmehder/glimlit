Glimlit in practice

A little interaction.
A few possibilities.

Glimlit is aimed at small interactive islands: a form, editor, filter, or widget within a larger page. The runtime provides the loop and lifetimes; each example chooses which state belongs in the model and which behavior belongs to the browser.
