Postcard Studio

A more advanced version of the tutorial’s postcard editor. The model uses distinct Title and Message types, including for empty drafts. Saving validates their contents and rejects empty or whitespace-only values. The view shows validation feedback, and restoring validates saved data too.

These types are an optional application design choice. The tutorial uses a simpler version to focus on MVU, effects, and subscriptions. Read the advanced source ↗ for the validation boundary and its comments. Its opaque types and validating functions live in text.gleam, separate from the app’s model and update. The view also explores Ramda’s cond for mapping themes and notices to presentation values.
