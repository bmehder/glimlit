Glimlit is a small framework for building web interfaces with Gleam and lit-html. It lets you give application decisions an MVU structure in Gleam while writing HTML-like views with lit-html and using browser elements directly. The framework keeps its scope to the loop, effects, subscriptions, and cleanup. Small interactive islands, such as forms, editors, and widgets within a page, are its primary use case. It offers another way to use Model–View–Update if you prefer that style of writing interfaces. Read about Glimlit on GitHub ↗ (opens in a new tab)
